## 4 типа данных и когда какой нужен
| тип | пример | для чего |
String - print ("Дима") - нужен для хранения текста
Int(integer) - print (31) - нужен для хранения целочисленных значений
Float - print(1.71) - нужен для хранения значений с плавающей точкой
Bool(Boolean) - family = True - нужен для хранения логических значений
